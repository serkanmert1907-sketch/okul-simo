Bağlantı ayarlanmadı
AI sonucu burada görünecek.

Nasıl çalışır?

  1. AI bağlantısı bölümüne kendi servisinin tam API adresini gir.
  2. Model adını ve gerekiyorsa kendi API anahtarını yaz.
  3. PDF’den veya ders notundan metni buraya yapıştır.
  4. “Sade anlat”, “Test hazırla” gibi bir işlem seç ve AI’ye gönder.
Güvenlik: API anahtarı varsayılan olarak yalnızca açık oturumda tutulur. “Bu cihazda hatırla” seçeneğini özellikle açarsan tarayıcıda saklanır ve şifreli değildir.

Not: Seçtiğin AI servisi tarayıcıdan gelen isteklere izin vermiyorsa (CORS), bağlantı başarısız olabilir. Bu durumda daha sonra küçük bir yerel/Cloudflare bağlantı katmanı eklenebilir.
